# GPTool-MapSync
MapSync is a professional-grade solution for updating and synchronizing map data sources. Built for GIS specialists, developers, and organizations that rely on accurate geospatial information, MapSync automates the process of refreshing map layers, integrating new datasets, and ensuring consistency across platforms.

## The Toolbox
The Toolbox contains two tools.
- [Change Map Data Source](#change-map-data-source)
- [Change Map Multiple Data Source](#change-map-multiple-data-source)

### Change Map Data Source
The tool modifies the map layers with new geodatabase as data source.

### Change Map Multiple Data Source
The tool modifies the map layers with new geodatabase as data source. If the Map has multiple data source, it updates each data source with a new geodatabase.
